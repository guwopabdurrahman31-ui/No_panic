# 공황패스 SOS — 공황발작 대처 가이드

공황장애가 있는 개발자가 실제 공황 발작 시 사용하기 위해 만든 **무료 오프라인 자가관리 보조 앱**입니다. 연구와 임상 가이드라인을 참고했으며, 웹 PWA와 Android 앱으로 제공합니다.

- **웹 접속 (GitHub Pages)**: `https://guwopabdurrahman31-ui.github.io/No_panic/`
- **주요 특징**: 
  - 100% 무료 / 광고 없음 / 서버 데이터 전송 전혀 없음 (`localStorage` 기반 기기 내 저장)
  - 인터넷 연결 없이 핵심 기능과 음악 작동 (`sw.js` 캐싱 및 Android 앱 내장 자산)
  - 임상 논문 및 가이드라인을 참고한 7가지 자가대처 방법, 부담 없는 집중 게임 2종 & 발작 시 직관적인 표지판 카드 모드 제공

---

## 🌿 주요 기능

1. **SOS 표지판 모드 & 가이드 모드**:
   - 발작 시 인지 능력이 저하되는 상황을 고려해 **큰 글씨 + 직관적 행동 지시형 표지판 카드** 제공.
2. **7가지 자가대처 방법**:
   - **숨쉬기**: 날숨 중심의 호흡 가이드
   - **찬기운**: 차가운 감각을 이용한 선택형 주의 전환
   - **사실되받기**: 파국적 생각을 사실과 구분하기
   - **파도 흘려보내기**: 공황을 억제하지 않고 흘려보내는 수용 관조 기법
   - **그라운딩**: 5-4-3-2-1 오감 자극 감각 인지
   - **적용 이완**: 전조 단계에서 어깨·손·발을 짧게 힘줬다 놓는 근육 이완
   - **편안한 심상**: 중립적이거나 편안한 장면의 세부에 주의를 두는 선택형 보조 방법

   각 방법의 근거 수준은 같지 않습니다. 앱 화면의 **이렇게 만들어졌습니다**에서 공황장애 직접 근거와 일반 불안에 대한 간접 근거, 앱용 짧은 변형의 한계를 구분해 안내합니다.
3. **증상 맞춤형 오프라인 진정 음악**:
   - 낮고 깊은 울림, 자연소리(빗소리/파도소리), 잔잔한 전자음 등 6곡 오프라인 재생 지원.
4. **승무원 카드 (도움 요청 카드)**:
   - 비행기 등 이동 중 발작 시 타인이나 승무원에게 전달할 안내 카드 (복용 약물/알레르기 기기 내 입력 가능).
5. **부담 없는 집중 게임 2종**:
   - **다른 하나 찾기**: 시간제한과 점수 없이 비슷한 모양 사이의 다른 하나를 찾는 5단계 게임.
   - **같은 그림 찾기**: 감점 없이 편안한 그림 3쌍을 맞추는 기억 게임.
   - 두 게임은 치료가 아닌 선택형 주의 전환 도구이며, 급성 공황발작에 대한 직접 효과 근거는 아직 없습니다.

## 📚 관련 문서
- [Play 제출 패키지](play-store/README.md): AAB, 아이콘, 스크린샷과 등록 자료

## 프로젝트 구성

- `index.html`, `manifest.json`, `sw.js`, `privacy_policy.html`: GitHub Pages 웹앱
- `assets/`: 웹과 Android 앱이 함께 사용하는 아이콘 및 오프라인 음악
- `app/`, `gradle/`: TWA가 아닌 일반 Android 앱 소스
- `play-store/`: Play 제출용 자료와 완성된 AAB/APK
- `scripts/`: Android 출시 빌드 및 스토어 스크린샷 도구

## Android 빌드

Android 앱은 TWA가 아닙니다. 웹 화면과 음악을 앱 번들에 포함해 일반 Android WebView에서 실행합니다.

```bash
./scripts/build_play_release.sh
```

## 🛠️ GitHub Pages 배포 설정 안내
GitHub repository (`guwopabdurrahman31-ui/No_panic`) 설정 페이지:
1. `Settings` -> `Pages` 로 이동
2. `Build and deployment` -> `Source`를 **Deploy from a branch** 로 선택
3. `Branch`를 **main** (또는 `master`) / **/(root)** 로 지정 후 Save 클릭
